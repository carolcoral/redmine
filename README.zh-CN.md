# Redmine

[English](README.md) | 简体中文

## Redmine 简介

[Redmine](https://www.redmine.org/) 是一款免费开源、基于 Web 的项目管理与问题跟踪（issue tracking）应用。

它基于 [Ruby on Rails](https://rubyonrails.org/) 框架构建，跨平台、跨数据库。

- 官方网站：**https://www.redmine.org/**
- 源代码：https://github.com/redmine/redmine

## 功能特性

- 支持多项目管理
- 灵活的基于角色的访问控制
- 灵活的问题跟踪系统
- 甘特图与日历
- 新闻、文档与文件管理
- Feed 与邮件通知
- 项目级 Wiki
- 项目级讨论区（论坛）
- 工时跟踪
- 简单机制的自定义字段
- LDAP 认证支持
- REST API
- SCM 集成（Subversion、Git、Mercurial 等）
- 多语言支持

## 运行环境

- Ruby 3.2 及以上（各 Redmine 版本的精确要求见 `doc/INSTALL`）
- 支持的数据库：PostgreSQL、MySQL / MariaDB 或 SQLite3
