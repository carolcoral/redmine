# Redmine Calendar Enhancement Plugin

基于 Redmine 6.1 版本的日历增强插件，提供便捷的日历交互功能。

## 功能特性

### 1. 双击创建问题
- 在日历视图中双击任意日期
- 弹出对话框快速创建新问题
- 可设置问题主题、开始日期、截止日期和指派人

### 2. 拖拽修改日期
- 拖拽日历中的问题到其他日期
- 自动更新问题的开始日期
- 实时保存并记录历史变更

### 3. 右键功能菜单
- 右键点击日历中的问题
- 快速修改问题指派人
- 删除问题（需有删除权限）

### 4. 活动记录
- 所有操作自动记录到活动流
- 创建、修改、删除操作都有详细记录

### 5. 历史记录
- 除删除操作外，所有对问题的操作都记录到问题历史
- 包含变更前后的值对比
- 便于追踪问题变更历史

## 安装步骤

1. 下载插件到 Redmine 的 plugins 目录
```bash
cd /path/to/redmine/plugins
git clone https://github.com/yourusername/redmine_calendar.git redmine_calendar
```

2. 安装依赖
```bash
cd /path/to/redmine
bundle install
```

3. 执行数据库迁移（如果需要）
```bash
bundle exec rake redmine:plugins:migrate RAILS_ENV=production
```

4. 重启 Redmine
```bash
touch tmp/restart.txt  # For Passenger
# 或重启你的应用服务器
```

5. 配置插件权限
- 进入 管理 -> 角色和权限
- 为角色分配 "编辑日历问题" 权限

## 配置选项

在 管理 -> 插件 -> 日历增强 中可配置：

- **显示问题右键菜单**：启用/禁用右键菜单功能
- **启用拖拽功能**：启用/禁用拖拽修改日期功能
- **启用双击创建问题**：启用/禁用双击创建问题功能

## 使用说明

### 创建问题
1. 进入项目的日历视图
2. 双击想要创建问题的日期
3. 填写问题信息并保存

### 修改日期
1. 鼠标按住要移动的问题
2. 拖拽到目标日期
3. 松开鼠标完成移动

### 修改指派人
1. 在问题上右键点击
2. 选择"更改指派人"
3. 选择新的指派人并确认

### 删除问题
1. 在问题上右键点击
2. 选择"删除"
3. 确认删除操作

## 权限说明

- **查看日历**：查看日历视图的权限（Redmine 内置）
- **编辑日历问题**：执行创建、修改、删除操作的权限（插件新增）
