# 2026-07-23

## setup-redmine.sh Ruby 版本自动管理
- 问题：脚本运行时未初始化 rbenv，导致使用系统 Ruby 2.6.10 而非 rbenv 管理的 3.3.6，bundle install 失败
- 新增 `setup_ruby_env()` 函数，在 step1 最先执行：
  - 自动检测并初始化 rbenv/rvm 环境
  - 解析 Gemfile 中 `ruby '>= X.Y.Z'` 约束
  - 版本比较（整数化 X*10^6+Y*10^3+Z）
  - 优先使用已安装的兼容版本（选最新）
  - 无兼容版本时自动 `rbenv install -s 3.3.6`
  - 自动设置 `rbenv local` 和 `.ruby-version`
- 修复了 macOS BSD sed 不支持 `\+` 正则语法的问题，改用 `*`
