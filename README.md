## About Redmine

[Redmine](https://www.redmine.org/) is a free and open source, web-based project management and issue tracking application.

It is cross-platform and cross-database, built on the [Ruby on Rails](https://rubyonrails.org/) framework.

- Official website: **https://www.redmine.org/**
- Source code: https://github.com/redmine/redmine

## Features

- Multiple projects support
- Flexible role based access control
- Flexible issue tracking system
- Gantt chart and calendar
- News, documents & files management
- Feeds & email notifications
- Per project wiki
- Per project forums
- Time tracking
- Custom fields with a simple mechanism
- LDAP authentication support
- REST API
- SCM integration (Subversion, Git, Mercurial and more)
- Multiple languages support

## Requirements

- Ruby 3.2 or newer (see `doc/INSTALL` for exact versions per Redmine release)
- A supported database: PostgreSQL, MySQL / MariaDB, or SQLite3
